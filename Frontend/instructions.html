User Manual

File Upload

  • Upload: Documents can be uploaded by dragging and dropping them or simply by selecting the files.
  • Supported formats:.v (Coq Source), .dpd (Graph Data).
  • You can select multiple files at once

Core Functions

  • Auto-Compilation: .v files are automatically compiled and analyzed by the backend.
  • Project View: If complete project is uploaded, then full dependency graph is rendered initially.
  • File Selection: Use the "Visualize" dropdown to filter the view for specific files.

Navigation & Controls

  • Zoom: Use the mouse wheel or the / buttons.
  • Pan: Click and hold anywhere on the background to drag the graph.
  • Sidebar: Toggle the menu with the button (top left).
  • Info: Click on any node/edge to see a tooltip with detailed metadata.

Analysis Tools

  • Search: Find nodes by ID or Name using the search bar. The node will be focused and highlighted.
  • Subgraph: Click on a node to select it (turns yellow). Then click "Visualize Subgraph" to open a new tab showing only this node and its direct neighbors.
  • Tip: "Search" feature is case-sensitive. User must input the correct node name or correct node id.

Smart Highlighting

  • Node Highlight: Select a category (e.g., Lemma) from the dropdown. Matching nodes glow yellow, others fade out.
  • Edge Highlight: Select a category to see how specific types are connected (displayed in blue).
  • Reset: Set dropdowns back to "Select" to restore the initial view.
  • Note: Highlighting feature and color coding feature is disabled, if .v files are not uploaded.

Layout Algorithms

Customize the arrangement via the "Layout" dropdown:

  • Cola / Klay: Best for general overviews.
  • Dagre: Hierarchical (top-down) view, great for dependencies.
  • Circle / Grid: Structured geometric views.
  • Auto-Switch: Large graphs (>200 nodes) defaults to Cola layout and smaller graphs to Klay layouts.

Export Data

  • PNG: High-res image (3x scale).
  • SVG: Infinite scalability (Vector).
  • PDF: Document format.
  • JSON: Raw graph data export.
